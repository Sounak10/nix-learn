# Exercises

Work through these files in numeric order:

1. `01-language.nix` — values, functions, and mapping.
2. `02-raw-derivation.nix` — construct a derivation directly.
3. `03-package-app.nix` — expose a package and runnable app.
4. `04-overlay.nix` — extend a package set.
5. `05-module.nix` — declare and define typed options.
6. `06-home-manager-shaped.nix` — evaluate user-configuration-shaped modules.
7. `07-nixos.nix` — define a minimal NixOS configuration.

Enter the lab with `./scripts/lab`, then evaluate or build the current file as
directed by its comments. Compare your result with the file of the same name
under `solutions/` only after attempting it yourself.

Run `./scripts/lab check` from the host to validate the repository examples
and solution set. That command checks whether exercise files parse, but it
does not grade unfinished `TODO` values.
